# DMT80480T070_18WT 简介

`DMT80480T070_18WT` 是迪文科技推出的一款 7 英寸 DGUS 智能串口屏，适用于工业控制、设备监控及人机交互等场景。

| 参数 | 说明 |
| --- | --- |
| 屏幕尺寸 | 7 英寸 |
| 分辨率 | 800 × 480 |
| 显示比例 | 5:3 |
| 开发平台 | K600+ / DGUS |
| GUI 开发工具 | K600+ DGUS Tool V5.x |
| 屏内程序 | 支持 DWIN OS 程序，生成 `23*.BIN` 文件 |
| 用户变量地址 | `0x0000`～`0x6FFF` |
| 工程下载 | 支持 SD/SDHC 卡及串口下载 |
| 背景图片 | 800 × 480、24 位 BMP |

> 设备的供电电压、串口类型（RS232/RS485）及端子定义可能因硬件版本不同而变化，请以设备背标和对应规格书为准。
